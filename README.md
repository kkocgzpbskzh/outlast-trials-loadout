## Overview

The Outlast Trials Loadout Planner helps players optimize their therapeutic rig selection and drug upgrade path for The Outlast Trials, comparing the stat effects of each loadout option against specific trial requirements and providing recommended loadout builds for different difficulty tiers and playstyles.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Outlast Trials Loadout Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Rig Comparison** | Side-by-side comparison of therapeutic rig stat effects |
| **Drug Upgrades** | Maps the upgrade tree for each drug category with effect values |
| **Difficulty Tiers** | Recommended loadouts optimized for Standard, Intermediate, and Advanced |
| **Trial Matching** | Suggests loadouts best suited to each specific trial's challenges |
